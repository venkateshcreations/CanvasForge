## ✨ Features & Architecture

- **100% Offline & Local-First**: Private, zero-account-lock-in desktop vector engine running at 60 FPS.
- **Native MCP Command Center**: Seamlessly connect AI design agents to your canvas via Model Context Protocol (MCP) JSON-RPC.
- **Figma Muscle Memory Parity**: Intuitive infinite canvas, layer reordering, component variants, smart guides, and interactive prototyping.
- **Vector Icons & UI Kits**: Built-in 300+ icon packs, SVG imports, and complete Apple/Material design system kits.
- **Visual Design System**: Dynamic color tokens, typography scales, shadows, shaders, and glassmorphism styling.
